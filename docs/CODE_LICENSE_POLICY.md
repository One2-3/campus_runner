# Campus Runner 자체 소스 코드 권리 정책

사용자 결정에 따라 **Campus Runner 자체 소스 코드에는 별도 오픈소스 라이선스를 부여하지 않는다.** 자체 코드의 재사용·수정·재배포 권한을 별도로 부여하지 않았으며 MIT·Apache 2.0·GPL 등을 프로젝트 전체에 적용하지 않는다. 확인되지 않은 저작권자 이름이나 연도를 새로 기입하지 않는다.

GitHub에 소스를 공개하는 것과 별도 코드 이용허락은 다르다. 다만 공개 저장소에 적용되는 GitHub 약관의 보기·포크 기능상 권리나 법률상 예외까지 부인하지 않는다. [GitHub 공식 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)를 함께 참고한다.

## 적용 범위

- 이 정책은 Campus Runner 자체 소스 코드에 대한 정책이다. 이미지의 재배포 권한을 임의로 부여하지 않는다.
- LibGDX·LWJGL·오디오 라이브러리·런타임·폰트 등 외부 구성요소에는 각 원래 라이선스와 고지가 적용된다.
- StartupHelper.java에 있는 damios의 Apache 2.0 고지는 유지한다.
- LGPL 구성요소의 수정 분석·교체 등 원래 라이선스상 권리를 자체 코드 정책으로 제한하지 않는다. [LGPL 안내](../packaging/LGPL_REPLACEMENT.md)를 참조한다.
- 나눔고딕 파생 폰트와 LSans에는 OFL이 계속 적용되며, 게임 자체 코드에 OFL을 확대 적용하지 않는다.

정책 결정은 완료됐다. 앞으로 소유자 승인 없이 별도 프로젝트 라이선스나 새로운 저작권자 표시를 추가하지 않는다. 외부 구성요소의 미해결 항목은 [최종 공개 점검표](PUBLIC_RELEASE_REVIEW.md)에 별도로 남긴다.
