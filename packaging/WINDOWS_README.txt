Campus Runner v1.0.0 — Windows x64

ZIP 전체를 압축 해제한 뒤 CampusRunner.exe를 실행하세요.
app, runtime, licenses 폴더를 EXE와 함께 유지하세요.
Java, Gradle, IDE를 별도로 설치할 필요가 없습니다.

방향키 위/아래: 메뉴 이동 / Enter: 선택
방향키 왼쪽/오른쪽: 이동 / Space: 점프 / Esc: 일시정지
자격증: 방향키 순서 입력
서버 연결: 방향키 선택 / Space 회전 / Enter 검사
성적표: Space로 엔딩 / 엔딩: Enter로 새 게임

이 패키지는 내부 실행 검증용 후보본입니다.
엔딩 폰트는 OFL 원본에서 재생성했습니다.
공개 배포 전 licenses/THIRD_PARTY_NOTICES.md의 이미지 출처,
생성 기록 및 남은 네이티브 라이선스 확인 사항을 해결해야 합니다.
자체 소스 코드에는 별도 오픈소스 사용권을 부여하지 않습니다.
외부 구성요소의 권리는 licenses/SOURCE_CODE_POLICY.md와 각 원문을 따릅니다.
