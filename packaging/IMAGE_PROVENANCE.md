# 게임 이미지 출처 기록 — 확인 사실과 사용자 설명

## 개별 파일

ASSET_INVENTORY.csv는 원본/리소스 53개의 경로·SHA-256·배포 포함 여부를 기록한다. 게임 이미지 34개와 런처 아이콘 7개를 각각 구분한다. 폰트 파일 9개는 GPT 이미지가 아닌 OFL 폰트 파생물이며 생성 리소스/셰이더 3개도 분리한다. IDE bin/main의 복사본 41개는 원본으로 집계하지 않는다.

## 사용자가 제공한 설명

확인일 2026-11-08, 이 대화에서 사용자가 제공한 설명:

- 게임 PNG와 런처 아이콘의 제작 출처 질문: “전부 ai 생성물임”.
- 생성 서비스와 시점 질문: “gpt로 파일 올린날.”

이에 따라 각 이미지의 출처를 사용자 확인 GPT 생성물로 기록했다. 정확한 모델 ID, 생성 달력 날짜, 프롬프트, 참조 입력, 생성 과정을 추측하지 않았다. 파일 수정 시간·Git 커밋 시각·현재 날짜를 원 생성 시각으로 바꾸어 적지 않는다. 로고 ICO/ICNS 변환 과정도 별도 증빙 없이 창작 과정으로 단정하지 않는다.

## 저장소·바이너리로 확인한 범위

- 해당 이미지 파일이 존재하고 게임이 사용하며, 배포된 이미지의 해시가 원본과 같다는 사실을 확인했다.
- 해시는 파일 식별·무결성 자료이며 창작자·권리·적용 약관을 증명하는 자료가 아니다.
- 원본 생성 대화나 이미지 생성 작업의 내보내기 기록은 저장소에 없다. AI 생성이라는 진술은 사용자 설명에 근거한 것으로 독립 검증 기록과 구분한다.
- PNG 청크 구조와 텍스트 메타데이터 유무를 조사했다. 메타데이터가 있더라도 서명·발급자 검증 없이 생성 서비스의 인증으로 간주하지 않는다.
- 검사한 게임/아이콘 원본 41개 중 PNG 9개에 caBX 자격증명 청크가 있었다. 서명 검증을 수행하지 않았으므로 이를 OpenAI 인증 또는 정확한 생성일 증빙으로 승격하지 않았다. 개별 파일의 관찰 결과는 ASSET_INVENTORY.csv의 metadata_evidence 열에 있다. 나머지 파일에서 청크가 없다는 사실도 AI 생성이 아니라는 증거로 사용하지 않는다.

## 이용 조건

[OpenAI 이용약관](https://openai.com/policies/terms-of-use/)의 출력 권리 조항을 확인했다. OpenAI와 사용자 사이의 출력 권리 귀속과 실제 법률상 저작권·제3자 권리·생성 당시 적용 약관은 구분한다. 별도 CC0/MIT 라이선스를 부여하거나 모든 이미지가 어떤 제3자 권리도 침해하지 않는다고 선언하지 않는다.

추가 확인이 필요한 자료는 정확한 생성 기록·생성 당시 서비스 조건과 필요한 입력 권리다. 확인 불가 상태를 출처 인증 완료나 무조건적인 재배포 허가로 표시하지 않는다. 프로젝트 자체 소스 코드에 대한 별도 오픈소스 사용권 미부여 정책도 이미지에 임의로 확대하지 않는다.
